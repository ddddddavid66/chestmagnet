# 宝箱磁铁 1.2.6：兼容与测试记录

Minecraft 1.20.1，Java 17。所有世界测试在独立目录进行，未改原整合包或原存档。

## 兼容范围

- 超越维度 Forge 0.8.9 ＋ CompixelUI 0.1.18（含 Kotlin）。先在超越维度选主网络，不用手持终端；只收玩家附近或当前结构中的来源。没有目标不会改走别的存储。
- FTB Quests 2001.4.22 ＋ FTB Library 2001.2.12，以及 2001.4.13 ＋ 2001.2.9。FTB 任务只读当前库存，分别核算随身背包、RS、超越维度，不跨网络叠加；不处理消耗、制作限定或界面提交任务。物品索引无法覆盖的特殊过滤条件仍按原任务机制处理。关闭吸附不会关闭检测；只要随身仍有开启任务检测的磁铁，就能继续检测。移走磁铁或关闭任务检测不会撤销已有 FTB 进度。
- 共振存储 1.5.1 用相同收取夹具做独立同装对照。不复制、不调用其内部代码；本夹具未观察到重复进度或扣除实物，不代表其它配置或版本没有冲突。
- 绯红教堂：探险者指南针 1.3.4；Goety Revelation 2.2.7 ＋ Goety 2.5.36.1，以及 2.3.6 ＋ Goety 2.5.60.6 ＋ EndingLibrary 2.2.3。教堂在下界。只有自动结构任务收模板预置的原生祭坛基座；黑暗祭坛、额外放置基座与普通／手动任务不参与。保留基座和世界原有仪式状态。

## 开销说明

固定同一客户端、镜头、限帧和测试世界，检测关／开短时采样。候选版（Forge 47.4.16，未装共振存储）帧时间 p50／p95：关闭 **8.645／15.673 ms**（300 帧）；开启 **8.473／11.163 ms**（470 帧）。这是短样本，没有观察到稳定回退，不能把启动缓存差异当成性能提升。服务器检测单步 p50 **0.250 ms**，含冷启动和 FTB 原生更新的 p95／最大 **15.005／37.665 ms**（19 个时间片）；软预算不能中断第三方一次原生调用。正式 JAR 的另一次对照：帧时间关闭 8.567／16.476 ms（260 帧）、开启 8.493／11.825 ms（454 帧）；服务端 25 个检测片段的 p50／p95／最大为 0.178／3.810／25.277 ms。检测只用剩余服务端预算、不做逐帧处理或全网络扫描；无可推进任务不打开库存视图。

## 复现

生产构建使用 JDK 17：`.\gradlew.bat clean dist "-PforgeVersion=47.2.18"`。构建所用的可选依赖 JAR 由对应上游取得，放入 `libs`，不随磁铁重新分发。新增的编译依赖文件名为 `beyonddimensions-0.8.9.jar` 和 `ftb-quests-forge-2001.4.22.jar`。开发测试用 `-Pverification -Pqa126`；旧 FTB 组合额外加 `-Pqa126Old`。带验证参数的 JAR 不是生产发行包。
