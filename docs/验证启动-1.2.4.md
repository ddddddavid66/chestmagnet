# 1.2.4 验证启动

所有命令从工程根目录的 PowerShell 运行。需要 Java 17、Python 3.11、Gradle 和 libs 中实际依赖；原包只读。不要同时运行多个 Gradle 构建，以免共享 build 目录相互覆盖。

## 服务端

```powershell
.\gradlew.bat runGameTestServer '-Pverification' '-Pqa124' '-Pminimal' -x downloadAssets
.\gradlew.bat runGameTestServer '-Pverification' '-Pqa124' '-PboosterVersion=41' -x downloadAssets
.\gradlew.bat runGameTestServer '-Pverification' '-Pqa124' '-PboosterVersion=41' '-PforgeVersion=47.4.16' -x downloadAssets
.\gradlew.bat runGameTestServer '-Pverification' '-Pqa124' '-PboosterVersion=41' '-PforgeVersion=47.4.18' -x downloadAssets
```

## 辅助模组与候选成品

先编译测试代码并提取独立辅助模组，然后干净重建生产 JAR；不要分发带 verification 参数的完整磁铁 JAR。

```powershell
.\gradlew.bat build '-Pverification' '-Pqa124' '-PforgeVersion=47.4.16'
python scripts/package-rs-qa.py build/libs/chestmagnet-forge-1.20.1-1.2.4.jar
.\gradlew.bat clean build
```

## 发行版客户端对照入口

```powershell
python scripts/rs-qa124.py --pack 'C:\Users\123\Desktop\mine craft\涟漪之\.minecraft' --magnet 'dist/[宝藏磁铁]chestmagnet-1.2.3.jar' --disk rs_integration:unified_storage_disk --mode active
```

脚本根据当前包的版本 JSON 启动，当前是 Forge 47.4.16。不是自动降级原包。每次运行创建 run/qa124-production-时间戳，日志、截图和测试世界留在该目录。

- --magnet 改成候选 JAR 路径用于新版；省略该参数用于无磁铁实例。
- --mode off / idle / active 分别为关闭、开启但无来源、持续补充测试桶；无磁铁组不具备自动收取。
- --disk 留空为普通存储块，rs_integration:unified_storage_disk 为归墟盘，rs_integration:resonance_storage_disk 为共振盘（工具保留该选项，但用户已取消共振盘及相关双盘组合测试，本轮无需执行）。
- 默认模板是无可选模组 GameTest 新建的测试世界，须先完成上述 minimal 命令；不能换成你的原存档。
- 辅助工具通过原生终端使用打开 20 次并等待 100 客户端 tick，记录列表、菜单、截图和服务端数量；有磁盘时安排 5 次取下/放回。归墟盘持续存入场景已由用户分别运行旧版和新版，各20次列表观察、5次取下/放回均未观察到空列表；此结果不替代包级验收。
- 空列表/无界面输出失败计数，未出现完成记录时脚本返回 2，不能记为通过。脚本超时会关闭它自己启动的 Java 进程。
- 如触发 Windows 沙箱 saves 路径限制，需恢复正常审批后再启动，不要修改原包权限或删除原数据来规避。

首次列表和增量同步包级探针、Curios 客户端重登录验证仍未实现完整自动化，需按测试记录中的未完成项继续补齐。
