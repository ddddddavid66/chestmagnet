# 宝箱磁铁 1.2.4 使用说明

Minecraft 1.20.1 / Forge 47.4.10–47.x / Java 17。客户端和服务器均替换旧版磁铁 JAR，不同时安装多个版本。保留 1.2.3 的操作、配置、存档及指南针和 Goety 兼容，原有操作见 [1.2.3 使用说明](使用说明-1.2.3.md)。

## RS 与饰品终端

选择 RS 目的地后，终端检查顺序为物品栏 0–35、副手、Curios 功能槽。Curios 槽按类型标识及槽号排序，外观槽不参与。前面的终端未绑定、没电或不可用时继续检查后续终端；使用的终端仍需满足原有供电、范围、跨维度卡和权限要求，实际存入按原有规则扣能。

Curios 为可选依赖；未安装时使用物品栏及副手。没有待交付物品和有效来源的空闲扫描不解析 RS 目标。本版本未改写 RS 终端界面，也不强刷库存列表。

## 配方

在工作台按以下位置放置，产出 1 个磁铁：

| | | |
|---|---|---|
| 铁锭 | 普通指南针 | 铁锭 |
| 金锭 | 箱子 | 金锭 |
| 铁锭 | 紫水晶碎片 | 铁锭 |

## 验证边界

Forge 47.4.10、47.4.16、47.4.18 的服务端 RS 回归已通过；归墟盘旧版与新版持续存入的客户端对照均未复现空列表。本版本作为兼容与查询开销改进发布，不将间歇空列表标为已修复。共振盘及相关双盘组合按用户要求不测。其余已完成及未完成项目见 [测试记录](测试记录-1.2.4.md)。
