# 宝箱磁铁 1.2.8 实测记录

此页记录 1.2.8 初版；同版本兼容修订的成品哈希和新增用例见[指南针兼容修订记录](指南针兼容修订-1.2.8.md)。

## 构建与安装

- Minecraft 1.20.1 / Java 17 / Forge 最低 47.2.18。正式 JAR 以该 Forge 版本构建；客户端用 Forge 47.4.16。
- 客户端和服务器都替换为 1.2.8（协议 8），不要同时保留 1.2.7。已发布的 1.2.7、原整合包、原存档未改动。
- 正式 JAR SHA-256：`40c5caf4d00afb1ff233747a9916a868068c89971825fcb69eeb854f5a1b56f3`。
- 正式构建：`gradlew.bat dist --offline -PforgeVersion=47.2.18`。测试通过独立的 `rsqa124.jar` 辅助模组驱动同一份正式 JAR，不使用开发环境替代成品；复现入口为 `scripts/qa128.py`。辅助 JAR 不应安装到正常游戏。

## 历史容量

每名玩家、每个存档最多保留五类各 256 条，共 1,280 条；「全部」临时合并出最新 256 条，不再存一份。请求只返回 8 条，私有 NBT 指纹不会发送给客户端。

使用带名称和摘要的 1,280 条合成记录：序列化 NBT **344,629 字节**，Gzip **15,766 字节**；这不是 JVM 内存，也不是任意存档的固定大小。预热后查询「全部」末页 512 次，两轮 p50 约 **0.043–0.079 ms**、p95 约 **0.105–0.155 ms**（仅服务端分页，不包括网络和渲染）。已核对普通物品刷满后饰品、附魔书等仍可查到。证据随本地交付的 evidence 目录附上。
